# Git-процес

1. Гілка від `main`: `feat/<slug>` або `fix/<slug>`; незавершене пушимо в `wip/<task>`.
2. Паралельні задачі — окремі worktree (`claude -w <name>`), а не `git stash`.
3. Перед комітом: `make check` зелений, `git diff --staged` переглянуто, у індексі лише свої файли.
4. Коміт — Conventional Commits; у тілі — причина зміни.
5. PR: опис «що і чому», як перевірено, ризики; злиття — лише після рев'ю людиною.
